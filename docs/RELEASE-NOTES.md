# Taskbar Menu 0.1.0

Standalone distribution of Taskbar Menu for Cinnamon 6.6.

- Create multiple independent application menus in the panel.
- Configure each menu's name, icon, panel display mode, and applications.
- Browse categories, search applications, and apply a selection with a category summary.
- Move the selection dialog by dragging its title bar.

Download `taskbar-menu-0.1.0.zip`, extract it, and copy the `taskbar-menu@cornelishaferkamp` folder to `~/.local/share/cinnamon/applets/`. Activate Taskbar Menu through System Settings → Applets. See README for details.
